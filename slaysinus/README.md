# SlaySinus

- **site/** — готовый сайт: `index.html`, картинки, стили и скрипты. Открывайте `site/index.html`. Для публикации загружайте содержимое этой папки целиком.
- **instructions/** — инструкции, описание обновления, дизайн и отчёт проверки. Начните с `instructions/README_UPDATE.md`. Инструкции v9 и v11 оставлены как история предыдущих версий.
- **database/** — SQL для настройки Supabase и добавления новой номинации в существующую базу.
- **materials/** — исходные изображения, промты генерации и скриншоты проверки. Эти файлы не нужны для публикации.
- **archives/** — готовый ZIP сайта, резервная копия исходной версии и дополнительный HTML-вход. Основной вход сайта находится в `site/`.

Готовый архив для загрузки: `archives/slaysinus_updated_site.zip`.

Пути в этой памятке и в инструкции обновления указаны относительно корневой папки проекта.

В сайт включена галерея из 54 фотографий и 6 видео. Инструкция по добавлению новых кадров находится в конце `instructions/README_UPDATE.md`.

Вход администратора с паролем, предложения пользователей и модерация: `instructions/ADMIN_AND_MODERATION.md`. Для существующей базы обязательно выполнить `database/slaysinus_moderation_migration.sql`.

Варианты фона и иконок главных ролей: откройте `materials/royal-options/index.html`. Для ролей используются названия Deer’s King / Deer’s Queen; идентификаторы категорий сохранены.

Подробный план бесплатной публикации в Word: `instructions/План_запуска_SlaySinus_за_0_рублей.docx`.
