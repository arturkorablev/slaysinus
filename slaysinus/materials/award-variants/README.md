# Варианты главных наград

Подготовлены три пары изображений в общем стиле остальных номинаций: дымчатый кристалл, янтарный свет, чёрный фон и небольшие осколки. На самих иллюстрациях нет надписей.

| Вариант | Олень года | Олениха года |
| --- | --- | --- |
| 1. Кристальный бюст | deer-01.webp | doe-01.webp |
| 2. Фигурка в полный рост | deer-02.webp | doe-02.webp |
| 3. Эмблема с лавром | deer-03.webp | doe-03.webp |

У оленя ветвистые рога, у оленихи естественные длинные уши без рогов. Все варианты представляют скульптуру награды, а не живое животное.

Откройте `preview.jpg`, чтобы сравнить все шесть изображений. WebP подготовлены для сайта; полноразмерные PNG сохранены в `originals/`. Точные промты и сведения о генерации записаны в `prompts.json`. Использован встроенный imagegen.

Варианты можно выбирать независимо: например, «Олень 1» и «Олениха 3».
