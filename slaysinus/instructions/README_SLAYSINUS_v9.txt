ПУБЛИКАЦИЯ НА CLOUDFLARE PAGES
1. Откройте site/index.html и укажите PUBLIC_SUPABASE_URL и PUBLIC_SUPABASE_KEY (только Publishable/anon key; никогда не вставляйте service_role или sb_secret в HTML).
2. В Cloudflare откройте Workers & Pages → Create application → Pages → Direct Upload.
3. Загрузите папку site целиком или ZIP содержимого папки site. Не загружайте отдельный index.html без assets.
4. Нажмите Deploy и проверьте сайт по адресу pages.dev.

ПОДКЛЮЧЕНИЕ ОБЩЕГО ГОЛОСОВАНИЯ
Если Supabase ещё не настроен, сайт откроется в локальном демо-режиме. Для общей базы выполните slaysinus_supabase_setup.sql в Supabase SQL Editor, создайте пользователя-администратора и добавьте его UUID в таблицу администраторов. Затем вставьте URL и Publishable key в site/index.html и повторно опубликуйте сайт.
