# Обновление SlaySinus

Откройте `site/index.html` или `archives/slaysinus_v11.html` в браузере. Корневой HTML использует файлы из `site/assets`, поэтому переносить его отдельно нельзя.

Для загрузки на Cloudflare Pages готов архив `archives/slaysinus_updated_site.zip`: внутри `index.html` и `assets`. Либо загрузите содержимое папки `site` целиком. Публикация из этой сессии не выполнялась.

Восемь обычных номинаций идут в заданном порядке в слайдере. «Олень года» и «Олениха года» выделены отдельными крупными карточками с фирменным кубком и кнопками перехода к своим номинантам. Всего в голосовании теперь десять номинаций.

Слайдер: стрелки, точки, клавиши ← → при видимом блоке, свайп, переход с последней номинации на первую. В полях ввода клавиши не перехватываются. Смена занимает 350 мс; при prefers-reduced-motion анимация отключена. Неактивные слайды исключены из фокуса, текущая номинация объявляется для скринридера. Высота определяется самым длинным слайдом, изображения квадратные и не меняют размер при перелистывании.

Восемь изображений 1024×1024 сгенерированы встроенным imagegen и сохранены в `site/assets/awards/`: alkash, team, ragebait, moldovan, project, meme, achievement, arrival. Формат WebP, суммарный вес 518094 байта. Только первая картинка загружается сразу, остальные при первом открытии слайда. Промты сохранены в `materials/image-prompts.json`.

## Общая база

Для уже подключённой Supabase-базы выполните `database/slaysinus_ragebait_migration.sql` в SQL Editor. Он расширяет допустимые значения nomination_id в candidates и votes, сохраняя данные. Без этого шага старая база отклонит кандидатов новой номинации.

Для новой базы используйте `database/slaysinus_supabase_setup.sql`. В нём также предусмотрено обновление ограничений существующих таблиц. Удалённая база в этой сессии не подключалась и не изменялась; SQL подготовлен для выполнения владельцем.

## Проверки

В Google Chrome через DevTools Protocol проверены все восемь слайдов на ширинах 360, 768 и 1440 px: один активный слайд, корректные картинки, текст внутри контейнера, отсутствие горизонтального переполнения. Проверены зацикливание, обе клавиши, настоящий touch swipe, точки, режим reduced motion, фильтрация кандидатов и работа клавиш внутри поля поиска. В изолированном локальном режиме добавлен тестовый рейджбайтер и принят голос. Ошибок JavaScript не обнаружено.

Скриншоты и обзор иллюстраций находятся в `materials/review/`. Это локальная проверка; сетевое голосование на реальной Supabase требует применения миграции и отдельной проверки с её настройками.

## Галерея «Наши моменты»

Виджет содержит 54 фотографии и 6 видео из предоставленной папки `fotki`. Все необходимые файлы находятся внутри `site/assets/moments/`, исходная папка для работы сайта не требуется. Весь сайт можно переносить и публиковать одной папкой `site/`.

Галерея устроена как лента: текущий кадр в центре, предыдущий и следующий по краям. У каждого кадра собственные пропорции, без обрезки и общей большой чёрной рамки. Соседние кадры можно нажимать. Для видео показываются статичные превью; воспроизводится только центральный ролик. На телефоне видны края соседних кадров.

При каждом открытии страницы случайным образом выбирается только стартовый кадр. Нумерация постоянно привязана к файлам: после кадра 37 следует 38, кнопка назад возвращает 36. После 60 идёт 1. Порядок не перемешивается. Номер `number` задан в списке файлов `site/assets/moments-media.js`.

Следующий материал открывается через 16 секунд после загрузки текущего. Стрелки, нажатие на соседний кадр, клавиши при фокусе в виджете и свайп по фото начинают отсчёт заново. Кнопка «Остановить смену» позволяет рассмотреть фото или досмотреть длинное видео. После включения смены снова отсчитываются 16 секунд. За пределами виджета и на скрытой вкладке таймер останавливается, видео ставится на паузу.

Видео запускаются без звука, если браузер разрешает автовоспроизведение. Звук и воспроизведение регулируются стандартными кнопками плеера. Клавиши и жесты внутри плеера сохраняют своё назначение. При prefers-reduced-motion появление кадра не анимируется.

Список файлов находится в `site/assets/moments-media.js`, соответствие исходным именам в `materials/moments-sources.json`. Соседние фото и постеры загружаются для превью; остальные видео заранее не загружаются.

Чтобы добавить материалы, поместите подготовленные файлы в `site/assets/moments/` и дополните массив в `site/assets/moments-media.js`. Путь `src` задаётся относительно `site/assets/`. Пример фотографии: `{ "type": "image", "src": "moments/photo-55.webp", "alt": "Описание", "number": 61, "width": 1200, "height": 1600 }`. Для видео используйте `type: "video"`, файл MP4 и поле `poster` с путём к изображению превью. Width и height задают размеры исходного кадра. После обновления заново упакуйте содержимое `site/` для публикации.

## Расположение результатов

Две главные категории, «Олень года» и «Олениха года», стоят первым рядом. Восемь остальных категорий идут ниже четырьмя рядами по две карточки. Ширина карточек одинакова, высота внутри каждого ряда выравнивается. На телефоне результаты перестраиваются в одну колонку. Настройки публикации результатов и подсчёт голосов сохранены.

## Модерация кандидатов и пароль организатора

Добавлены предложения посетителей с проверкой администратором, публикация/скрытие, редактирование, удаление, изменение числа голосов и крупные карточки с фото/видео. Вход администратора через email и пароль Supabase; свободный демо-вход удалён. Подробные шаги обновления и настройки аккаунта: `instructions/ADMIN_AND_MODERATION.md`. Код основного приложения теперь в `site/assets/app.js`.
